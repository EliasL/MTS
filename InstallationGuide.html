2. Setup

3. Launch

Open MTS.app / MTS.desktop in this folder. Select Quit MTS to stop the server.

Reopen the same browser address while the server is running. Local storage retains session authorization until Quit MTS. MTS.html links to the current session.

Launcher approval may be required.

VS Code
  1. Open the top-level MTS folder. Select .venv/bin/python for Python.
  2. With CMake Tools, select MTS2D/CMakeLists.txt and the release preset (CMake ≥ 3.21). On macOS, select Apple Clang at /usr/bin/clang++.
  3. Use Terminal → Run Build Task → Build managed simulator. This records the build identity required for managed runs at MTS2D/build/release/MTS2D.

The debug preset builds scientific tests in MTS2D/build/debug. Build folders and personal VS Code settings are ignored by Git.

Troubleshooting

Check the operation log or .mts/server.log and .mts/launcher.log. Quit MTS before rerunning setup. Rerun setup after moving the project.

Terminal launch: bash setup.sh --start.
