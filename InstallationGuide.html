Getting started

A local home for your simulations.

Set up the tools you need, then open MTS from a launcher in this folder. Your browser is the interface; your computer does the work.

1. Choose what you need

No login service

Python and its packages are managed for this workspace. Existing component checkouts are preserved. Missing submodules are downloaded at the versions recorded by MTS.

2. Run one command in Terminal

Open a terminal and paste the command below. You do not need to activate Python or navigate to this folder first.

The command prepares a Python runtime if necessary, then opens the setup progress in your browser. Keep the Terminal window open until installation is complete.

First installation needs an internet connection and Git. Use a Git clone of MTS; ZIP installation will be supported separately.

3. Open MTS whenever you need it

After installation, open MTS.app or MTS.desktop directly in this folder. It starts MTS and opens your browser. Nothing is registered to run when you sign in.

MTS.html links to the current browser session and provides startup help. Use the desktop launcher to start a new session, and Quit MTS inside the application to stop it.

Your operating system may ask you to approve a newly created launcher.

Troubleshooting

Read the operation log in the Setup page for installation or build errors. Startup logs are stored in .mts/server.log and .mts/launcher.log in this folder.

If setup was interrupted, rerun the same command. If MTS is still running, quit it first or use its Setup page to repair packages. If the folder has moved, rerun setup to regenerate environment links and launchers.

The launcher can also be started from Terminal with the same command plus --start.

MTS supports macOS and Linux. Compiler installation is optional and uses system tools only when you select assisted setup.
