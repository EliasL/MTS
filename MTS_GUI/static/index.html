SSH connections

Check account access and deployed versions. Check connections checks enabled sites in parallel; individual checks also support disabled sites. Deploy: grey until checked, green when current, red when an update is needed, white when absent.

Install SSH key

Generate an Ed25519 key and install its public key using the account password. The private key remains on this computer. Password and keyboard-interactive authentication are supported; additional MFA prompts require manual setup.

Add SSH connection

Adds an OpenSSH alias and an MTS site profile. Check the host fingerprint and install a key before deploying the server manager.
