Execution

System 1 drives in x from the left edge, or from the right edge for −1. System 2 drives in y from the bottom edge, or from the top edge for −2. Use a single sign per system. The decimal fraction sets the split along the edge and defaults to 0.5. Each entry applies one full slip.

Horizontal loading moves the upper half of the constrained nodes in x. Vertical loading moves the right half in y. The split is at the midpoint.

Additional settings
Use segment load to switch directions during a run. It sets how much load to apply before advancing to the next entry in the direction sequence. For example, with horizontal,vertical and a segment load of 0.1, the run applies 0.1 of horizontal load before switching to vertical. Repeat sequence cycles back to the first direction. Otherwise the final direction continues until the run ends.

SSH connections

Check account access and deployed versions. Check connections checks enabled sites in parallel; individual checks also support disabled sites. Deploy: grey until checked, green when current, red when an update is needed, white when absent.

Install SSH key

Generate an Ed25519 key and install its public key using the account password. The private key remains on this computer. Password and keyboard-interactive authentication are supported; additional MFA prompts require manual setup.

Add SSH connection

Adds an OpenSSH alias and an MTS site profile. Check the host fingerprint and install a key before deploying the server manager.
